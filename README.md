## 지도 마커와 확대 단계별 분리 (v1.3.1 변경 제안 · 미배포)

- 일반 장소 및 묶음 모두 **36×36px** 크기입니다. 묶음 안에는 작은 폴더 그림과 **위치 수만** 표시하며, 공연·리셀·센토 등 전체 유형 구성은 선택 후 정보 카드에서 확인합니다.
- **10~13레벨**에서는 화면 거리 40px 미만일 때만, **14~15레벨**에서는 26px 미만일 때만 묶습니다. 기존의 58/62px 판정 및 독립 묶음끼리의 연쇄 재병합을 제거하여 인접하지 않은 장소가 함께 묶이지 않도록 했습니다.
- **16~18레벨**에서는 거리 기반 묶음을 사용하지 않습니다. 같은 지점에 여러 공연·매장·장소가 있어도 각 항목을 개별 아이콘으로 표시합니다. 아이콘끼리 42px 미만으로 겹치는 경우 화면상 아이콘을 방사형으로 벌리고 선과 점으로 **원래 좌표**를 표시합니다. 저장된 위도·경도는 바꾸지 않습니다.
- GSI 주소 검색으로 얻은 위치는 여전히 **주소 구역 기준 대략 좌표**일 수 있습니다. 아이콘을 분리해도 건물 출입구 정밀도가 좋아지는 것은 아니며 실제 입구는 매장 상세 및 외부 지도에서 확인해야 합니다.
- 모바일에서는 묶음 첫 선택 시 구성 정보를 먼저 보여주고 별도의 **지도 확대** 버튼으로 확대합니다. 16레벨 이상 개별 아이콘을 탭하면 해당 장소를 선택할 수 있으며 바텀시트·시간/지역/리셀 필터·찜 데이터는 보존합니다.
- 수정 파일: `index.html`, `map-marker-system.js`, `map-mobile-ux.css`. 테스트: `node --test tests/map-cluster-init.test.mjs tests/map-marker-categories.test.mjs tests/map-mobile-ux.smoke.test.mjs`. 실제 모바일 기기에서의 시각적 최종 확인은 별도로 필요합니다.
- 해당 동작은 `fix/map-cluster-density-spiderfy-20261102` 작업 브랜치의 **미병합 변경**이며, 실제 운영 페이지에 적용됐다는 의미가 아닙니다.
