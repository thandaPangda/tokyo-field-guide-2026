## 지도 마커와 확대 단계별 분리 (v1.3.1 변경 제안 · 미배포)

- 일반 장소 및 묶음 모두 **36×36px** 크기입니다. 묶음 안에는 작은 폴더 그림과 **위치 수만** 표시하며, 공연·리셀·센토 등 전체 유형 구성은 선택 후 정보 카드에서 확인합니다.
- **10~13레벨**에서는 화면 거리 40px 미만일 때만, **14~15레벨**에서는 26px 미만일 때만 묶습니다. 기존의 58/62px 판정 및 독립 묶음끼리의 연쇄 재병합을 제거하여 인접하지 않은 장소가 함께 묶이지 않도록 했습니다.
