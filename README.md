# TOKYO FIELD GUIDE 2026

2026년 11월 11–15일 도쿄 여행을 위한 모바일 우선 탐색 가이드입니다.

## 포함된 콘텐츠
- 공연 40건, 전시·아트 21건, 장소 96곳(센토 22곳 포함).
- 낮/밤 탐색, 지역별 묶음, 지도, 전체 검색, 개인 찜.
- '동행 픽' 등 추천 태그 및 흡연 환경 정보와 필터.
- 신주쿠의 모츠야키 카미야 포함.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 별도 빌드 과정이 필요 없습니다.

## GitHub Pages
저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택하고,
`main` 브랜치의 `/(root)`를 지정해 게시할 수 있습니다.

## 주의사항
- 영업 시간, 행사 일정, 예약 및 흡연 정책은 바뀔 수 있으므로 방문 전에 확인하세요.
- 일부 매장의 흡연 가능 여부는 확인되지 않았습니다.
- 외부 지도 타일, 장소 좌표 검색 및 외부 콘텐츠는 네트워크 환경에 따라 제한될 수 있습니다.
- 찜 데이터는 브라우저의 `localStorage`에 저장되며 기기 간 자동 동기화되지 않습니다.
