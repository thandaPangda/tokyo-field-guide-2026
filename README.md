# TOKYO FIELD GUIDE 2026

2026년 11월 11–15일 도쿄 여행을 위한 모바일 우선 탐색 가이드입니다.

## 포함된 콘텐츠
- 공연 40건, 전시·아트 21건, 장소 96곳(센토 22곳 포함).
- **정보 탭**: 포켓몬 카드 구매 가이드(공식 포켓몬센터·편의점 취급 미확인 구분·코엔지 인근 후보·지역 필터)와 2026-11-01 일본 면세 환급제도(출국 전 세관 확인·영수증 거래 단위·포장 규정 변경).
- 낮/밤 탐색, 지역별 묶음, 지도, 전체 검색, 개인 찜.
- '동행 픽' 등 추천 태그 및 흡연 환경 정보와 필터.
- 신주쿠의 모츠야키 카미야 포함.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 별도 빌드 과정이 필요 없습니다.

## GitHub Pages
저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택하고,
`main` 브랜치의 `/(root)`를 지정해 게시할 수 있습니다.

## 정보 탭과 근거

- [포켓몬 카드·면세 리서치 및 정책 분류](research/info-guides-pokemon-taxfree-2026-11-01.md): 2026-11-01 기준 공식 출처와 사용자 경험담의 차이를 기록합니다. 실제 편의점 판매 여부와 재고는 보장하지 않습니다.
- 직접 진입 경로: `#info`, `#info/pokemon`, `#info/taxfree`. 정보 탭은 여행 일정 자체를 자동으로 변경하지 않습니다.
- `info-tab.js`, `info-tab.css`는 정보 화면을 담당하며, 스크립트 실행이 불가능할 때는 축약된 기본 안내를 표시합니다.

## 검증

- Node.js가 있다면 `node --test tests/info-tab.smoke.test.mjs`로 정보 탭의 모의 DOM 회귀 검사를 실행할 수 있습니다. 실제 모바일 브라우저 조작은 별도 확인이 필요합니다.

- [CHANGELOG.md](CHANGELOG.md): 처음 게시한 v1.0.0과 미출시 변경안을 구분한 버전별 패치 노트. 이후 모든 수정 사항은 이 파일에 누적 기록합니다.
- [2026-10-29 흡연 정책 후기 재조사 보고서](research/smoking-reviews-2026-10-29.md): 상시 장소 74건, 센토 22건, 공연장 22건(중복 포함)을 검토한 자료입니다.
- [AGENTS.md](AGENTS.md): 이후 코드·데이터·디자인·여행 정보 수정 시 패치 노트를 함께 기록하도록 하는 프로젝트 운영 규칙입니다.

**주의:** 조사 보고서에 표시된 흡연 정책 변경은 실제 `index.html`의 데이터·필터에 자동 적용되지 않습니다. 패치 노트의 `미출시` 항목은 PR 병합 및 사이트 반영 전의 제안 내용입니다. PR 승인·병합은 저장소 소유자가 직접 진행합니다.

## 주의사항
- 영업 시간, 행사 일정, 예약 및 흡연 정책은 바뀔 수 있으므로 방문 전에 확인하세요.
- 일부 매장의 흡연 가능 여부는 확인되지 않았습니다.
- 외부 지도 타일, 장소 좌표 검색 및 외부 콘텐츠는 네트워크 환경에 따라 제한될 수 있습니다.
- 찜 데이터는 브라우저의 `localStorage`에 저장되며 기기 간 자동 동기화되지 않습니다.
