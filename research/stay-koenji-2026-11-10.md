# 고엔지 숙소: 호스트 자료 근거와 미확인 범위 (2026-11-10)

## 원자료
사용자가 제공한 Miduki 호스트의 Airbnb 메시지와 15페이지 '高円寺101Ver2.pptx .pptx.pdf'를 기준으로 정리했습니다. 원본 PDF에는 비공개 출입 정보가 있어서 공개 GitHub 저장소에 업로드하지 않았습니다.

## 페이지별 근거
- PDF 2쪽: 녹색 대문, 101번 키박스, 원본의 와이파이 네트워크, 욕실 비품, 연락 경로. 공개 코드에는 출입 비밀번호·와이파이 암호·전화번호를 제외했습니다.
- PDF 3쪽: 16:00 이후 체크인, 10:00 이전 체크아웃, 숙소 주소, JR 고엔지역, 방과 공용 공간 배치, 낯선 사람에게 출입문 열어주지 않기.
- PDF 7~9쪽: 고엔지역 남쪽 출구부터 숙소 녹색 대문까지 사진별 이동 단계. 9쪽 마지막 집의 위치는 중국어 설명과 영어 설명의 좌우가 달라 직접 단정하지 않았습니다.
- PDF 10쪽: 에어컨 및 욕조 온수 패널의 일본어 조작 명칭.
- PDF 11쪽: 세탁기 전원, 코스, 시작, 세탁·건조 등 일본어 버튼 명칭.
- PDF 12쪽: 퇴실 전 열쇠 반납, 청소업체 대기 시 시간당 2,000엔 청구 가능성에 관한 호스트 문구.
- PDF 13쪽: 가연성·불연성·재활용 쓰레기 구분, 숙소 쓰레기통 이용, 외부 집하장 금지, 10,000엔 벌금에 관한 호스트 문구.

## 호스트 메시지 우선 적용
- 숙박객은 1층 개인실을 사용하고, 화장실·욕실·세면대는 호스트 및 다른 게스트와 공용입니다.
- 2층은 호스트 가족의 생활 공간이며 아기가 있습니다. 주방 사용은 허용되지만 정리되어 있지 않을 수 있습니다.
- 냉장고·전자레인지·세탁기는 이용할 수 있고, 세탁 세제는 게스트 지참입니다.
- 욕실에 샴푸와 바디솝이 있고 1인당 목욕 수건 1장이 제공됩니다. 칫솔·치약·슬리퍼는 직접 준비합니다.
- 체크인 전과 체크아웃 후 녹색 대문과 현관 사이에 무료로 짐을 둘 수 있다고 안내했습니다. 조기 체크인은 유료 가능성을 문의해야 합니다.
- 호스트는 게스트 등록 양식을 작성해 달라고 요청했습니다. 일본 법률상 필요하다는 설명은 호스트 주장이며 사이트에서 별도 법률 검증을 한 것은 아닙니다.

## 미확인 내용 및 주의사항
- PDF의 쓰레기 10,000엔과 청소 대기 2,000엔 문구는 호스트 안내서의 설명이지 보편적으로 적용되는 법정 벌금이라고 판정하지 않았습니다.
- 주방 사용 가능 외에 조리도구·식재료 제공 여부는 확인하지 않았습니다. 냉장고·전자레인지·세탁기 외의 기기 사용 권한도 임의로 추가하지 않았습니다.
- 숙박의 정확한 체크인/체크아웃 날짜는 제공된 화면에서 전체 예약 기간이 확인되지 않아 표기하지 않았습니다.
- 실제 PDF의 길안내 사진을 웹에 복제하거나 PDF 원문을 GitHub에 재게시하지 않았습니다. 사용자가 등록한 원본 링크를 통해 열 수 있도록 했습니다.

## 구현 및 보안 방식
- 기존 정보 탭에서 #info/stay로 진입합니다. 모바일 상단에 체크인·퇴실, 지도, 주소 복사, 원본 연결을 배치하고 생활 정보는 주제별로 제공합니다.
- 공개 JavaScript와 CSS에는 출입 PIN, 와이파이 암호, 호스트 전화번호, 원본 비공개 Drive 파일 ID를 넣지 않았습니다.
- 사용자가 직접 입력하고 저장을 누른 경우에만 개인 브라우저 localStorage에 보관합니다. 이는 암호화되지 않아 공유 기기나 외부 스크립트가 접근할 위험이 있으며, 브라우저 데이터 삭제로 유실될 수 있음을 고지합니다.
- 원본 PDF 링크는 HTTPS drive.google.com/file/d/.../view 형태만 유효한 링크로 처리합니다. 이 URL은 공개 저장소에 들어가지 않습니다.
- 모바일 실기기 테스트, GitHub Pages 공개 배포와 Google Drive 실제 공유 권한은 별도로 검증해야 합니다.
